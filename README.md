# Shell_Archieve_Project
Introduction :
This project is based on shell scripting, in which a file of size greater than 20 MB are zipped and saved into another folder archieve.

Steps followed in the script : 
1. Provide the path of the directory in which the large files are present.
2. Check if the directory path exists or not.
3. Create an archieve folder if not already present.
4. Go through all the file and find the files larger than 20MB.
5. Compress each file.
6. Move the file into an archieve folder.
7. Make a cron job to run at a particular moment of time according to you.(Note : This step is taken outside the script)

Purpsoe of this Project :
1. This script is very useful in the envoirnment where a large log files or other files are generated on daily basis.
2. It compress those large files and save it into an archieve folder so that the data could not be lost.
3. It helps in saving the disk space/storage of an envoirnemnt or device.
4. Reduces the cost and make the efficient use of the space.
